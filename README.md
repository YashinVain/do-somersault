# Ныряй!

Аркада про прыжки в воду с вышки. Делается на Unity для Яндекс Игр. Название рабочее.

Игрок стоит на краю платформы, приседает и клонится к воде, отпускает — прыгает. В воздухе можно группироваться, чтобы крутиться быстрее, и раскрываться, чтобы замедлиться. Задача — войти в воду ровно и попасть в круг из буйков.

## Управление

Одна кнопка: левая кнопка мыши, касание экрана или пробел.

- Держишь на вышке — персонаж приседает и наклоняется вперёд. Чем дольше держишь, тем дальше прыжок. Передержишь — сорвётся с края.
- Отпускаешь — толчок.
- Держишь в воздухе — группировка, вращение ускоряется.
- Отпускаешь — раскрытие, вращение замедляется.

## Очки

- Очки дают только за вход в воду внутри круга из буйков. Мимо круга — ноль.
- 100 очков за каждые пол-оборота.
- Бонус за вход: головой ровно +150, головой с наклоном +75, солдатиком ровно +60, солдатиком с наклоном +30.
- Вход в круг удваивает очки. Если задел верёвку с поплавками — без удвоения.
- Плашмя, срыв с края, удар о вышку — ноль.
- Бомбочка (вошёл в воду в группировке) считается отдельно и даёт немного.

Оценки судей на экране результата — для атмосферы, на очки не влияют.

## Как открыть

1. Unity **6000.3.24f1**. Проект на встроенном рендере (Built-in RP), ввод через старый Input Manager.
2. Unity Hub → Add → Add project from disk → папка репозитория.
3. Сцена `Assets/_Project/Scenes/Pool_Prototype.unity` открывается сама при первом запуске. Нажмите Play.

Папки `Library`, `Temp`, `Logs`, `UserSettings` не хранятся в репозитории, Unity создаст их при открытии.

## Как это устроено

**Сцена собирается кодом.** `PrototypeSceneBuilder` строит всё с нуля: окружение, вышку с четырьмя платформами (3, 5, 7,5 и 10 м), персонажа, всплеск, интерфейс, меню. Правки внешнего вида делаются в сборщике, потом сцена пересобирается. Так сцену легко сравнивать в git и пересоздавать без ручной расстановки.

**Персонаж — набор деталей на шарнирах.** Плечи, локти, бёдра, колени, голеностопы и спина поворачиваются кодом в `DiverPose`. Позы (стойка, присед, группировка, «стрелка» для входа головой) плавно перетекают друг в друга. Готовой анимации нет, позже персонажа заменит модель из Blender.

**Вращение — по физике.** В момент толчка задаётся момент импульса. Дальше скорость вращения считается как момент импульса, делённый на момент инерции тела в текущей позе. Группировка уменьшает инерцию — персонаж крутится быстрее, раскрытие увеличивает — медленнее. Полёт считается для центра масс, тело расставляется вокруг него.

**Наклон на краю сам себя разгоняет**, как падающий столб: чем сильнее наклон, тем быстрее он растёт. Поэтому долгое удержание кончается срывом.

**Вышка твёрдая.** Точки тела (голова, кисти, колени, носки, пятки) сталкиваются с коробками платформ и опор, удар меняет и скорость, и вращение.

## Инструменты редактора

Меню **Jump Game** в Unity:

- **Build Prototype Scene** — пересобрать сцену.
- **Capture Dive Frames** — прогнать несколько прыжков без запуска игры и сохранить кадры в `Logs/capture_*.png`. Удобно смотреть движение, не играя.
- **Tune Level Medals** — для каждого уровня перебрать около тысячи вариантов прыжка (сила толчка × длина группировки), найти лучший возможный результат и выставить медали: золото 80% от него, серебро 55%, бронза 30%. Заодно проверяется, что задание уровня выполнимо.

Если меняется раскладка уровня (дистанция, радиус круга, задание), пороги этого уровня надо подобрать заново через Tune Level Medals.

## Уровни

16 уровней на одной вышке. Первые восемь знакомят с высотами и заданиями, вторые восемь добавляют маленькие и движущиеся круги, задание без группировки, 3 оборота с десяти метров. Следующий уровень открывается с бронзовой медалью.

## Планы

- Шрифт с кириллицей вместо стандартного Arial, звуки воды и интерфейса.
- Модель персонажа из Blender с костями.
- Вторая локация (озеро или скала у моря) со своими уровнями.
- Яндекс Игры: SDK, облачные сохранения, реклама за награду, лидерборд.
- Сборка WebGL под требования площадки.
